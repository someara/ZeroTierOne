AES-GMAC-SIV SIMD OPTIMIZATION - IMPLEMENTATION SUMMARY
================================================================================

OBJECTIVE:
Eliminate 2x performance gap between Zig (914 MiB/s) and C++ (1911 MiB/s)
AES-GMAC-SIV implementations by using unsafe SIMD pointer operations.

USER DECISION:
Accept unsafe code to achieve C++ performance parity. The 2x gap is not
acceptable for production deployment.

PHASE 1: Platform-Specific SIMD Modules ✅
------------------------------------------
Created two new modules with unsafe pointer operations:

File: src/node/aes_simd_x86.zig (~280 lines)
- SSE + AES-NI baseline (processes 64 bytes/iteration)
- Placeholders for AVX-512 + VAES (needs Zig intrinsics)

File: src/node/aes_simd_arm.zig (~160 lines)

- Safe fallback for remainders <64 bytes
- No API changes (drop-in replacement)
