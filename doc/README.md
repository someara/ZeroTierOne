# Manpages

`doc/` contains the manpage sources for ZeroTier commands.

Build them with `./build.sh` in this directory.

You will need either:

- Node.js/npm so the script can install and use `marked-man`, or
- `ronn` from RubyGems or your distribution packages

This directory is separate from the repository docs in `README.md`, `DEVELOPMENT.md`, and `TESTING.md`.
