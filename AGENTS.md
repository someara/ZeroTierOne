# Agent Instructions

- Read `ZIG.md` for roadmap, priorities, support levels, and subsystem scope.
- Read `DEVELOPMENT.md` and `TESTING.md` for commands.
- Treat `build.zig` as the final command truth.
- Read `STYLE.md` and `CODING_STANDARDS.md` before changing Zig code.
- Do not infer Zig parity from `service/README.md`.
- Do not infer implementation status from file presence, type names, or TODO counts.
- Do not answer "how close are we" with percentages or broad completion claims unless a current doc or verified run proves it.
- Report `verified`, `untested`, `blocked`, and `broken` separately.
- Do not claim `complete`, `production ready`, or `should work` without end-to-end proof.
- `tshark` and `tcpdump` are available.
